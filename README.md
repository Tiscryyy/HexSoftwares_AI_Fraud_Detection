# AI Fraud Detection System

## Project Overview
This project is a beginner-friendly Artificial Intelligence application that explores how machine learning can be used to detect fraudulent financial transactions. The goal of the project is to understand how AI models identify unusual patterns in transaction data and assist in fraud prevention.

This project was developed as part of the HexSoftwares Artificial Intelligence Internship Program.

## Problem Statement
Financial institutions process a large amount of transactions every day. A very small percentage of these transactions are fraudulent, which makes fraud difficult to detect. 
This project demonstrates how machine learning can be used to automatically detect potentially fraudulent transactions based on historical data.

## Dataset
The project will use a publicly available credit card transaction dataset containing both normal and fraudulent transactions. Due to privacy and legal constraints, real South African bank transaction data is not publicly available. However, the techniques demonstrated in this project can be applied to financial institutions in South Africa and other regions.

The dataset contains anonymized transaction features and a class label indicating whether a transaction is fraudulent or legitimate.

## Approach
The project follows these main steps:
1. Load and explore the transaction dataset
2. Analyze the class imbalance between fraudulent and non-fraudulent transactions
3. Preprocess the data for machine learning
4. Train machine learning models to classify transactions
5. Evaluate model performance using appropriate metrics

- Learn how machine learning models are trained and evaluated
- Gain hands-on experience with Python and machine learning libraries
